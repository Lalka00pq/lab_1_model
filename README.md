# Лабораторная работа № 1 — моделирование динамических рядов

Приложение загружает временной ряд из CSV, строит и сравнивает скользящее
среднее, экспоненциальное сглаживание и квадратичный тренд. Для квадратичного
тренда вычисляются две гармоники Фурье, оцениваются остатки и формируется
прогноз.

Расчеты и чтение CSV используют стандартную библиотеку Python. Для графиков
используются seaborn и matplotlib.

## Запуск

Из корня проекта:

```bash
uv run lab-1-model
```

Либо указать собственные входной файл и каталог результатов:

```bash
uv run lab-1-model --data src/lab_1_model/data.csv --output output
```

Также доступен запуск как модуля:

```bash
uv run python -m lab_1_model
```

В `output/` сохраняются отчет, таблица исходных данных и рассчитанных
компонент, таблица прогноза и каталог `graphs/` с графиками исходного ряда,
сравнения трендов, гармонического анализа, итоговой модели, остатков и
прогноза. Используются исходные неокругленные значения; в отчете числа
выводятся с шестью знаками после запятой.
